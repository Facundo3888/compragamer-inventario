# Sistema Integral de Gestión de Inventarios - CompraGamer

## Descripción del Proyecto
Este repositorio aloja la documentación técnica y el modelado de procesos del **Trabajo Práctico Integrador Final** para la materia Organización Empresarial. 

El proyecto consiste en el diseño de un software de gestión de inventarios para la empresa CompraGamer, con el objetivo de sincronizar en tiempo real el módulo de Ventas (plataforma de e-commerce) con el módulo de Logística (escáneres físicos en el depósito).

## Objetivos del Sistema
*   Automatizar el descuento de stock físico mediante lecturas de códigos de barras.
*   Evitar la venta de artículos sin existencias reales en la plataforma web.
*   Aplicar el principio de interdependencia sistémica entre las áreas operativas.

## Documentación Incluida
*   **Diagrama BPMN:** Modelado del flujo de compra y sincronización.
*   **Diccionario de Datos:** Estructura de las entidades críticas (`Producto`, `Pedido_Web`, `Escaneo_Logistica` y `Detalle_Pedido`). 

## Declaración de Uso de Transparencia y IA
En cumplimiento con los lineamientos de la cátedra de Organización Empresarial, se declara que durante el desarrollo de este Trabajo Práctico Integrador se utilizaron herramientas de Inteligencia Artificial Generativa bajo un enfoque de uso crítico, activo y complementario.

*   **Propósito de uso:** La IA fue empleada como apoyo para la estructuración formal del documento, la revisión de sintaxis, la validación teórica de las entidades del Diccionario de Datos y la correcta aplicación del estándar BPMN.
*   **Prompts utilizados:** Se formularon instrucciones orientadas a la consulta conceptual (por ejemplo, validación de la interdependencia sistémica y etapas del control administrativo) y a la auditoría de consistencia de los diagramas.
*   **Correcciones humanas efectuadas:** Los resultados generados por los asistentes fueron auditados, corregidos y adaptados manualmente para reflejar con precisión la realidad operativa de la empresa CompraGamer y ajustarse a los criterios de la cátedra, asumiendo la autoría y responsabilidad intelectual total del proyecto.
