# Sistema Integral de Gestión de Inventarios - CompraGamer

## Descripción del Proyecto
Este repositorio aloja la documentación técnica y el modelado de procesos del **Trabajo Práctico Integrador Final** para la materia Organización Empresarial. 

El proyecto consiste en el diseño de un software de gestión de inventarios para la empresa CompraGamer, con el objetivo de sincronizar en tiempo real el módulo de Ventas (plataforma de e-commerce) con el módulo de Logística (escáneres físicos en el depósito).

## Objetivos del Sistema
*   Automatizar el descuento de stock físico mediante lecturas de códigos de barras.
*   Evitar la venta de artículos sin existencias reales en la plataforma web.
*   Aplicar el principio de interdependencia sistémica entre las áreas operativas.

## Documentación Incluida
*   **Diagrama BPMN:** Modelado del flujo de compra y sincronización.
*   **Diccionario de Datos:** Estructura de las entidades críticas (`Producto`, `Pedido_Web`, `Escaneo_Logistica` y `Detalle_Pedido`).
